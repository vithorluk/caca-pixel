# Caça-Pixel

Jogo de tiro ao pássaro em pixel art. Uma tela roda o jogo e os celulares são as armas: aponte o celular para a tela e toque para atirar.

Jogue em https://vithorluk.github.io/caca-pixel/

1. Abra o endereço na TV ou no computador e escolha "Esta é a tela do jogo".
2. Leia o QR code com cada celular e toque em "Entrar como arma".
3. Aponte para o centro da tela e toque em "Calibrar".
